# Answer key stays in the database

When a quiz is created, the answer key is stored in the database. The learner's browser receives the questions and the choices. Grading compares the submitted choices to the stored key in code. The model does not grade.

Amended by [Answer key shown after grading](0007-answer-key-shown-after-grading.md) and then [Answer key shown for each question as it is checked](0009-answer-key-shown-per-question.md): the key of a question stays in the database until that question is checked.
