# An empty profile keeps being asked

PR-02 says an empty profile is filled before any teaching. The reply asks for what is missing and does not teach yet. The writer runs when the session ends, not on each reply. During a session whose profile is still empty, every later reply asks again and still does not teach.

Teaching anyway in that session was the alternative, and it was rejected: a missing stored fact is not a reason to flip PR-02. After the session ends and the pass stores facts, later sessions teach from them.
