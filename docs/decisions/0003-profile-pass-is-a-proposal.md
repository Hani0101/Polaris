# Profile pass is a proposal

The teaching agent reads the profile and does not write it. The candidate writer is a separate model, in the class of Haiku, because the job is simple reading of the session. It runs when the learner leaves the session, including when they switch to another session. It decides which milestones are true, and sends fact changes as ADD, UPDATE, DELETE, or IGNORE. A repeated fact, such as "I suck at math", stays one stored fact.

This design has not been compared with alternatives. Refuse to implement profile writing until a research note accepts this design or replaces it.
