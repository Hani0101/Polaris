# Lottie guides

Reference notes on Lottie structure, motion taste, and design taste. They are
copied from the `text-to-lottie` skill in
https://github.com/diffusionstudio/lottie (MIT, see `LICENSE`) and are given to
the Lottie animation writer as part of its system prompt.

Polaris plays scenes with lottie-web, not Skottie, and has no slots, controls,
or scene folders. The writer prompt says which parts of these notes to ignore.
